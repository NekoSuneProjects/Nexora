# E2EE chat integration preview
The browser now encrypts and decrypts chat messages using the existing WebCrypto primitives and a locally unlocked passphrase-protected device. The API stores only ciphertext JSON envelopes, and checks current guild epoch during insertion. The API provides device-scoped wrapped-key storage and increments guild epochs on membership changes.

**Important unsafe limitations:** This is a **single-device, single-member bootstrap only**. Multi-member or multi-device key distribution is intentionally denied without verified grants. After a membership change, keys must be rotated, and previous epochs remain inaccessible in this preview. Identity fingerprints come from server-provided directories and are not externally pinned or key-transparent. The client assumes the local key's own fingerprint when opening a key grant, not a complete verified multi-device trust graph. No independent cryptographic audit has occurred. Do not use for sensitive conversations or claim that E2EE is production ready.
